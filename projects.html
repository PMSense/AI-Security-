Slam AI Security Data Protection Product Management Projects

Projects

Notebooks and hands-on machine learning / security projects, with a short description of what each one does.

  • Poisoning Attack Pipeline
    Poisoning_Attack_Pipeline_vFinal3.ipynb

    Demonstrates adversarial data-poisoning attacks against a Random Forest network intrusion detection system (NIDS). Injects mislabeled malicious traffic into the training data to show how even a small amount of label corruption can catastrophically degrade detection of DoS attacks.

  • Project 1 — Digit Classification with KNN
    Slam_Laqtib_project1_2.ipynb

    Digit classification on the MNIST dataset using k-nearest neighbors and other machine learning techniques, with visualization of digit samples and analysis of how different parameters affect accuracy.

  • Project 2 — Digit Classification with Naive Bayes
    Slam_Laqtib_project2_1.ipynb

    Digit classification on MNIST using several Naive Bayes variants (Bernoulli, Multinomial, Gaussian), including image preprocessing with Gaussian blur filtering and hyperparameter tuning via grid search.

  • Project 3 — Newsgroup Text Classification
    Slam_Laqtib_project3_1.ipynb

    Text classification of newsgroup posts into four topics (atheism, graphics, space, religion) using bag-of-words feature extraction, comparing k-NN, Naive Bayes, and Logistic Regression with different preprocessing and regularization strategies.

  • Project 4 — Mushroom Clustering & PCA
    Slam_Laqtib_project4_1.ipynb

    Applies PCA to reduce a 126-feature mushroom dataset to 2 dimensions for visualization, then uses k-means clustering and Gaussian Mixture Models to classify mushrooms as poisonous or non-poisonous.
